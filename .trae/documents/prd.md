## 1. 产品概述

一款复古像素风格的机甲对战小游戏，支持双人对战。两名玩家各自操控一台像素机甲，在封闭场景中进行实时对战，通过移动、攻击、防御等操作击败对手。

- 核心玩法：两名玩家在同一屏幕上使用不同按键控制各自的机甲，通过攻击削减对方生命值至零获胜
- 目标用户：休闲游戏玩家、复古像素游戏爱好者
- 产品价值：提供轻量、爽快的本地多人对战体验，无需联网即可游玩

## 2. 核心功能

### 2.1 玩家角色

| 角色 | 操控方式 | 核心能力 |
|------|----------|----------|
| 玩家1（红色机甲） | WASD移动，F攻击，G防御 | 移动、近战攻击、防御格挡 |
| 玩家2（蓝色机甲） | 方向键移动，J攻击，K防御 | 移动、近战攻击、防御格挡 |

### 2.2 功能模块

1. **对战主场景**：像素风格封闭战场，包含地面和障碍物
2. **机甲角色**：两台不同颜色的像素机甲，带基础动画
3. **战斗系统**：攻击、防御、受伤、胜负判定
4. **HUD界面**：血条显示、胜负提示、操作说明
5. **游戏状态管理**：开始、进行中、结束、重新开始

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 战场场景 | 像素风格地面、背景装饰、封闭边界 |
| 游戏主界面 | 机甲角色 | 两台像素机甲，站立/移动/攻击/防御/受伤动画 |
| 游戏主界面 | 战斗系统 | 攻击命中判定、防御减伤、血量计算 |
| 游戏主界面 | HUD | 双方血条、操作提示、胜利/失败文字 |
| 游戏主界面 | 游戏控制 | 开始画面、重新开始、暂停功能 |

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：复古8-bit像素风格，NES时代美学
- **主色调**：深色背景（#1a1a2e），红色机甲（#e63946），蓝色机甲（#457b9d）
- **场景颜色**：地面（#2d6a4f），天空渐变（#0d1b2a → #1b263b）
- **字体**：使用像素风格字体（Press Start 2P 或 monospace）
- **按钮样式**：像素块状按钮，无圆角，粗边框
- **布局风格**：居中画布，上下信息栏
- **HUD风格**：8-bit风格血条，块状填充

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主界面 | 战场 | 800x600像素画布，地面纹理，边界围墙 |
| 游戏主界面 | 机甲 | 16x16像素角色，4方向站立，3帧攻击动画 |
| 游戏主界面 | HUD | 顶部血条（红/蓝），中间战斗状态文字 |
| 游戏主界面 | 开始/结束 | 半透明遮罩，大字提示，操作说明 |

### 4.3 响应式

- 桌面优先，固定画布尺寸 800x600
- 画布在页面中居中显示
- 适配不同屏幕分辨率

### 4.4 游戏机制详细设计

- **攻击**：攻击距离约60px，造成10点伤害
- **防御**：防御时减少70%伤害（受到3点伤害），有1秒冷却
- **生命值**：每台机甲100点生命值
- **移动速度**：每帧3px
- **攻击冷却**：0.5秒
- **攻击后摇**：0.3秒（攻击后短暂僵直）
- **受击后摇**：0.2秒（受击后短暂僵直）
- **胜负条件**：一方生命值归零则游戏结束

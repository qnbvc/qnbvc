# 03 · 开源工具清单与合规基线

> 目标：回答答题要求 ⑤ 中的「工具清单」，同时把评价指标 4「安全合规（授权边界、限速、最小权限、日志审计、非破坏性）」落成可执行的规则。

---

## 一、选型原则

1. **只选许可清晰的开源工具**，且全部可离线部署（比赛现场网络受限）。
2. **按安全档位分级调用**：默认只跑被动档，主动档必须显式授权才启用。
3. **工具只负责"出证据"，不做结论**——结论由智能体的去重/验证/分级层给出，避免误报直接进报告。
4. **能力可替换**：同一能力同时准备主选与备选工具（如模板扫描失败降级为被动指纹比对）。

> ⚠️ 许可证以各项目仓库的实际 LICENSE 为准；商业交付前必须复核，特别关注 **GPL / AGPL** 组件的使用方式（AGPL 在对外提供服务时有额外义务）。

## 三、安全档位定义（写进代码的硬约束）

| 档位 | 含义 | 允许的行为 | 典型工具 |
| --- | --- | --- | --- |
| **T0 被动采集** | 只读、无 payload、状态不变 | GET 页面与公开资源、DNS 查询、证书透明度、内容与文本分析 | httpx、katana、gitleaks、YARA |
| **T1 受控探测** | 请求特定路径/模板，可能产生异常日志，但不改变数据 | 目录与文件探测、模板化非入侵 POC、配置基线扫描、TLS 配置探测 | nuclei（排除危险模板）、nikto、feroxbuster |
| **T2 主动验证** | 可能改变状态或产生高请求量，**默认全局关闭** | 注入验证、XSS 验证、弱口令检测 | sqlmap、dalfox、Wapiti |

启用规则：`T2 需同时满足 ① 该资产授权条目显式开启 active ② 处于允许时间窗 ③ 单资产请求预算未超限`，三者缺一不可。

## 四、危险操作禁用清单（默认拒绝，且不允许"配置绕过"）

| 类别 | 禁止项 |
| --- | --- |
| 口令类 | 弱口令爆破、账号枚举、撞库 |
| 注入类 | time-based/布尔盲注、数据导出（dump）、写入型 payload |
| 上传与执行 | 文件上传、WebShell 植入、命令执行验证 |
| 资源类 | DoS/压力测试、触发 DOS 类模板、超大字典全量 fuzz |
| 写操作 | 任何会修改数据的 POST/PUT/DELETE/PATCH（除授权的只读型查询接口） |
| 范围 | 请求授权范围外资产、默认禁止跨域跳转跟随 |
| 通道 | 不使用真实用户凭据、不使用生产后台账号 |

## 五、授权与巡检范围配置样例（规范形式）

```yaml
# authorization.yaml —— 真实实现建议用 YAML；本仓库骨架代码用等价 JSON 以避免额外依赖
authorization:
  id: "AUTH-2026-0912-001"
  owner: "某单位网络安全负责人"
  valid_from: "2026-09-01"
  valid_until: "2026-12-31"
  document: "evidence/auth-2026-0912.pdf"     # 授权书存证，到期自动熔断

scope:
  domains:
    - "*.example.gov.cn"                       # 通配子域
    - "portal.example.gov.cn"
  ip_ranges:
    - "203.0.113.0/24"
  url_prefixes:
    - "https://portal.example.gov.cn/"
  exclude:
    paths: ["/admin/export", "/api/personal/*"]  # 排除路径，绝不请求
    patterns: ["*?download=*"]                    # 排除规则
  max_depth: 3
  max_concurrency: 4
  max_requests_per_run: 20000
  follow_redirects_offsite: false                # 默认不跟随出授权域

schedule:
  cron: "0 2 * * *"          # 每天 02:00
  window: "02:00-05:00"      # 仅在该时间窗内发请求
  freeze_dates: ["2026-10-01", "2026-10-02"]

rate_limit:
  per_domain_qps: 5
  global_qps: 20
  user_agent: "SecurityInspector/1.0 (+authorized-scan; contact=secops@example.gov.cn)"

safety:
  default_tier: "T0"        # 默认只跑被动档
  active_assets: []         # 显式列出的资产才允许 T1
  allow_active_tier: []     # T2 需显式授权，默认空
  deny_actions: ["bruteforce", "sqli_dump", "file_upload", "dos"]

sensitive_rules:
  keywords:
    - "内部资料"
    - "仅供内部使用"
    - "身份证号"
  regex:
    - name: "中国大陆手机号"
      pattern: "(?<!\\d)1[3-9]\\d{9}(?!\\d)"
    - name: "身份证号"
      pattern: "[1-9]\\d{5}(19|20)\\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\\d|3[01])\\d{3}[\\dXx]"
    - name: "AccessKeyId"
      pattern: "(?i)(access[-_]?key[-_]?id)\\s*[=:]\\s*[A-Za-z0-9]{16,}"
  file_types: ["pdf", "doc", "docx", "xls", "xlsx", "zip", "rar", "sql", "bak", "env", "log"]
  samples:
    - "evidence/sample-report.docx"      # 样例文件 → 自动生成指纹（片段哈希 + 模糊匹配）
  whitelist:
    - "示例数据 13800000000"              # 白名单，命中不告警
  masking: "partial"                     # 证据展示时部分脱敏

notify:
  channels:
    - type: "email"
      to: ["secops@example.gov.cn"]
      min_level: "P1"                    # 仅 P0/P1 立即告警
    - type: "webhook"
      url: "https://im.example.gov.cn/hook/xxx"
  quiet_hours: "22:00-07:00"             # 静默窗口，P0 除外
```

## 六、检测效果自评方法（对应 30% 指标）

先自建靶场，再算指标——不要等到被评委测试才发现误报爆炸。

**靶场构成建议**

| 类别 | 样例 |
| --- | --- |
| 漏洞 | 存在已知 CVE 的旧版本组件、缺失安全头、目录列表、`.git` 可访问 |
| 篡改 | 基线后修改正文/插入外链/插入隐藏 iframe/替换图片 |
| 挂马 | 混淆 JS、外域脚本引入、疑似 WebShell 文件 |
| 泄露 | 页面含身份证/手机号、可下载的备份包、PDF 内含内部标注、JS 中硬编码 AK/SK |
| 干扰项（负样本） | 正常外链、示例数据、公开的联系电话——**用于压误报** |

**指标定义**

```
召回率 Recall   = 命中真实风险数 / 真实风险总数
准确率 Precision = 命中真实风险数 / 系统报告风险数
误报率 FPR      = 误报数 / 系统报告风险数
去重有效率       = (原始命中数 - 去重后数) / 原始命中数
```

**验收线建议**（自定目标，向上对齐评委预期）

- 高危类召回 ≥ 90%，误报率 ≤ 10%；
- 篡改/挂马类召回 ≥ 85%（这类靠基线，最容易做成 100%）；
- 敏感信息类召回 ≥ 85%，且白名单必须完全不告警。

## 七、合规自检表（提交前逐项打勾）

- [ ] 范围外域名请求被**拦截并记录**，日志可演示
- [ ] 全局限速与域名级限速可配置，且有实际生效证据（请求时间戳分布）
- [ ] T2 档默认关闭，开启需要显式授权 + 二次确认
- [ ] 危险操作清单中的行为在代码层不可达（而不是"文档写了不做"）
- [ ] 所有出站请求带自定义 UA，含联系邮箱
- [ ] 授权到期后系统拒绝执行
- [ ] 审计日志覆盖：谁、何时、对哪个资产、用了哪个工具、多少请求、结果
- [ ] 证据中的敏感值已脱敏；原始值加密存储
- [ ] 无任何写操作、无文件上传、无口令爆破
- [ ] 所有工具的许可证已核对，AGPL/GPL 组件的使用方式已确认
